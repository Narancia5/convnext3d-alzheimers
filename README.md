# Alzheimer's Disease Early Detection with ConvNeXt Neural Network

This is a semi-finished research project on early Alzheimer's detection using neural network.

Alzheimer's Disease (AD) is a neurodegenerative disease, that has become more and more common in our aging society. As currently incurable, the ultimate task is to detect it preliminary, so that medical intervention can slow progression and delay certain symptoms. Several studies provided approaches for AD classification or progression detection from different biomarkers, one of the most prominent being brain atrophy, which is generally analyzed with magnetic-resonance imagery (MRI) scans. To put emphasis on progression detection in order for early intervention, this paper presents a method, which can detect progression between three brain funcionality stages: normal cognitive, mild cognitive impairment and AD, from two longitudinal MRI scans using the OASIS-2 dataset. The approach employs a Siamese neural network structure and ConvNeXt model for feature extraction.
